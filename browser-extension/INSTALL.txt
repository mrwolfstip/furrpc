furrpc browser media

Chrome, Edge, Brave, Arc, Vivaldi and other Chromium browsers:
1. Open the browser's Extensions page.
2. Turn on Developer mode.
3. Choose Load unpacked and select this folder.

Firefox:
1. Open about:debugging#/runtime/this-firefox.
2. Choose Load Temporary Add-on.
3. Select manifest.json in this folder.

Keep furrpc running. The extension only sends the title and playback timing of
the currently playing tab to 127.0.0.1 on this Mac. Remove it from the browser's
Extensions page whenever you no longer want browser media tracking.
